# Optional: your CardShop Plus content goes here

In a source checkout, you can put the contents of your own CardShop Plus CD in this folder,
keeping the original upper-case names (`CARDSHOP.INI`, `ART/`, `BDAY/`, `FONTS/` …), or unzip a
private OpenCardShop asset pack over the project folder. Installed copies use
**File → Open another asset folder…** instead. OpenCardShop works without this content, using
its open starter pack. See "What you can make cards with" in the main README.

Everything in this folder except this README is ignored by git. Never commit it.
